# Dream Home Builder

ich möchte eine homepage bauen für einen verkauf eines Neubaus. hier muss ein berechner drauf, visualisierungen von den Wohnungen oder von einem teil der Wohnungen dann ein Berechnungstool, in dem man die Einheit auswählen kann mit Zins Tilgung Eigenkapital und den Kaufpreis übernimmt es fest aus der angeklickten Einheit. dann sonder AFA 5 % bei Anlegern und noch eine Auswahlmöglichkeit für Eigennutzer.

dann soll man in die Wohnung gehen können also das es visualisiert ist.

eine Baubeschreibung soll rein und einzelne visualisierungen von bad wohnen sagen und Besonderheiten (Balkon/terasse) 

Preisliste soll rein Wohnungsliste muss rein, Visualisierung muss rein

Mikro und Makrolage muss rein.
